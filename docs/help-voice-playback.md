# Голосовые Help: постоянная расшифровка и восстановление

Актуальность: 8 ноября 2026. Аудитория: IT и администраторы. Среда: dev.

Этот документ заменяет описание кеша 64 записи / 15 минут и автоматического распознавания шести последних голосовых от 7 ноября. Завершённые расшифровки теперь сохраняются в PostgreSQL HelpAudioTranscript без TTL, на весь срок жизни вложения; внешний ключ удаляет запись только вместе с вложением. Смена модели, API/worker или повторное открытие неизменившегося аудио не запускают распознавание заново.

Автоматически обрабатываются только новые входные сообщения текущего задания, включая последовательные сообщения до ответа ИИ. История получает уже сохранённый текст, без отправки старого аудио в speech API. При активной работе IT отдельная фоновая очередь распознавания не создаётся. Старую запись без результата можно обработать по кнопке или явным вызовом help_read_attachment. Основная модель остаётся gpt-6.1-sol/medium; speech — gpt-transcribe.

API и worker используют общую атомарную PostgreSQL-аренду по вложению: конкурирующий запрос получает pending, а не создаёт второй вызов. Завершённый текст или no_speech сохраняются постоянно; незавершённая аренда истекает через 180 секунд для восстановления после аварии. Сетевой сбой с неопределённым исходом не позволяет обещать абсолютную однократность платного внешнего запроса.

GET /help/attachments/:id/transcript только читает статус. POST с пустым объектом распознаёт или возвращает сохранённый результат; pending сопровождается HTTP 202. Статусы: not_started, pending, transcribed, no_speech, unavailable. После запуска закрытие экрана не отменяет серверное распознавание: оно ограничено независимым сроком 110 секунд. Клиент отменяет только своё ожидание; раскрытие текста не требует нового распознавания.

Каждое чтение проверяет доступ к сервису, обращению, авторство и привязку вложения. Размер, SHA-256, MIME и источник проверяются до отправки провайдеру и перед сохранением/выдачей. Текст остаётся данными исходного автора, не получает полномочий системной инструкции и не переписывает оригинальные сообщения. Секреты OpenAI, прокси и права 1С остаются серверными.

Лимиты: 20 МиБ на запись; до 32000 символов с явной отметкой усечения; общий бюджет автоматических новых записей 120 секунд. Поддерживаются M4A/MP4, WEBM, MP3, WAV, OGG и FLAC. Исторический материал не расходует этот бюджет на повторное распознавание.

APP: кнопка справа от голосового читает готовый текст перед POST, при pending опрашивает GET. Анимируется рамка; ошибка останавливает анимацию и допускает повтор. Текст раскрывается под сообщением по измеренной высоте на UI thread за 220 ms. Reduced motion отключает анимации. Смена аккаунта/обращения и переиспользование ячейки блокируют запоздавшую выдачу. Нет дополнительного владельца прокрутки или IME. Повторное раскрытие в смонтированной карточке не выполняет запросов.

Кеш самого аудиофайла остаётся отдельным от постоянной расшифровки: собственная запись копируется после upload ACK до удаления черновика, кеш разделён по API/аккаунту/вложению. Прогресс передачи измеряется по байтам. Плеер автоматически закрывается только по фактическому окончанию воспроизведения; пауза его сохраняет.

Аддитивная миграция 20261108010000_help_audio_transcripts применяется только через scripts/apply-help-audio-transcripts.cjs в подтверждённой LeaderAPI_dev. Скрипт проверяет checksum HelpSchemaVersion, структуру и FK; все исторические миграции запускать нельзя. Для восстановления сохранять действующие private Compose/env, ключи, mounts и права. Возврат на старый runtime не требует удаления таблицы или текстов.

Проверки и развёртывание: API и Help worker обновлены на leaderproductapi:help-voice-mail-dev-20261108-r1; оба healthy, посторонние контейнеры не менялись. Применены две аддитивные миграции аудио и почты. Изолированные проверки PostgreSQL: 12 для аудио и 10 для почты; писем не отправляли. Из dev-контейнера проверены TLS SMTP обоих провайдеров, это не проверка пароля конкретного ящика. Metro bundles web/Android отвечают HTTP 200. Клиентские изменения Metro-only; OTA/APK, перезапуск T3/Metro и визуальная проверка устройства не выполнялись. Доказательства находятся в .dev-runtime/help-voice-mail-20261108/; содержимое голосов, личные данные и секреты в этом документе отсутствуют.
