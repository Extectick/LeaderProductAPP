# Активный web-чат и прокрутка боковых полей Help

Два исправления Help, 07.11.2026: подтверждение прочитанного события в активном web-чате учитывается при доставке push на другие устройства пользователя; колесо мыши над пустыми боковыми полями прокручивает текущую переписку.

## Присутствие и подтверждение события

Web считается активным только при `document.visibilityState=visible` и фокусе окна. `HelpNotificationsBridge` публикует состояние при visibilitychange, focus и blur; обработчики удаляются при завершении подписки. На native сохраняется проверка AppState. Открытая, но скрытая или не сфокусированная вкладка не является подтверждением чтения.

API подавляет push на другом устройстве только при ACK вида chat для конкретного события от действующей активной сессии того же пользователя в том же обращении. Срок сессии должен ещё действовать. Одного presence без ACK недостаточно. ACK вида banner подтверждает показ только на собственном устройстве; событие другого обращения, истёкшая или неактивная сессия не подавляют cross-device push. Существующие проверки доступа, настроек уведомлений, прочитанной последовательности и учёт доставки по токену сохраняются.

## Колесо мыши над пустым полем

`useHelpWebMarginWheel` устанавливает обработчик только на desktop web-панель текущего чата. Он реагирует на собственный пустой фон панели (`event.target === node`) и передаёт вертикальную прокрутку реальному scroll node `HelpTimeline`. Вложенные элементы и их прокрутка сохраняют обычное поведение. Ctrl+wheel остаётся масштабированием браузера, преимущественно горизонтальное движение и уже обработанное событие пропускаются.

Дельты px/line/page переводятся в пиксели с учётом высоты viewport. Timeline сохраняет единственное владение прокруткой, якорями, подгрузкой истории и ручным выходом из следования за концом чата. Дополнительный ScrollView не создаётся. Обработчик отключён вне активной переписки, во время перехода, поиска, модальных окон, галереи и других перекрывающих экранов. Native-поведение не меняется.

## Восстановление

APP: `HelpNotificationsBridge.tsx`, `HelpScreen.tsx`, `useHelpWebMarginWheel.ts`, `components/HelpTimeline.tsx` в `src/features/help`. API: `src/modules/help/help.delivery.ts`; подробный контракт — `docs/help-assistant-delivery.md`. Техническая инструкция хранится в Nextcloud с доступом IT/admin, ограниченный архив исходников/runtime/доказательств — в закрытой папке «Восстановление компании». Снимок содержит текущие версии scoped-файлов и может включать конкурентные изменения; перед восстановлением согласовать их с актуальной веткой. Env, ключи, пароли, токены, переписки, пользовательские файлы и скриншоты в архив не включаются.
