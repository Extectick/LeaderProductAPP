# Семантика строки файла и отмена загрузки Help

Исправление APP через Metro, 07.11.2026. В `HelpFileRow` кнопка отмены загрузки находилась внутри основной кнопки файла. React Native Web преобразует обе в настоящий HTML `button`, поэтому дерево содержало запрещённую вложенность. Во время загрузки внешняя кнопка была disabled и могла дополнительно блокировать действие отмены. Параметры `rotation`/`origin` у SVG-круга также приводили к выдаче библиотекой атрибута `transform-origin`, на который React сообщал как на некорректное DOM-свойство.

## Структура действий

Основной `Pressable` файла сохраняет семантику кнопки: название действия, состояния busy/disabled и обычное скачивание или повтор. Кнопка отмены расположена соседним элементом в общей обёртке, поверх существующей области иконки размером 56×56 dp. Для варианта assistant учтён прежний горизонтальный отступ 12 dp. Оформление и зона отмены сохранены; кнопка доступна отдельно от disabled-состояния основной загрузки.

Отмена отображается только при загрузке с доступным `onCancel`, не при отправке. Событие отмены останавливает всплытие, поэтому оно не вызывает скачивание. Управление AbortSignal, прогрессом, текущим аккаунтом и временем жизни операции остаётся у существующего вызывающего компонента. Новый транспорт загрузки или обход проверок доступа не добавлены.

Круг прогресса использует SVG `transform="rotate(-90 28 28)"` вместо комбинации `rotation`/`origin`. Процент, длина окружности, штрих и начало движения сверху сохраняются; некорректное свойство больше не генерируется в web-дереве.

## Статусы доставки в обычном сообщении

`HelpMessageBubble` помещает статус доставки с собственной кнопкой повтора ниже строки файла. Такой статус не передаётся как trailing-содержимое внутрь кнопки скачивания. Это относится к queued/sending/failed доставке. Метка времени успешно доставленного файла остаётся компактной внутри строки, поскольку отдельной кнопки повтора в ней нет.

## Проверки

Добавлен DOM-набор с настоящими `react-native-web`, `react-dom` и web-элементами `react-native-svg`. Он проверяет отсутствие `button button` и ошибок React, самостоятельный фокус и нажатие отмены, disabled основной кнопки, обновление SVG-прогресса, состояния idle/ready/failed/cancelled, неизвестный размер и отправку. В JSDOM проверяются семантика и непрерываемые события клавиш; нативная браузерная генерация click клавишей там не имитируется как доказанная визуальная проверка.

Регрессии компонентов покрывают внешний статус доставки, повтор отправки, скачивание и отмену. Пройдено 79 тестов в 5 наборах, включая 7 DOM-тестов; TypeScript без ошибок, Expo Doctor 20/20, зависимости актуальны. Доказательства сохраняются в `.dev-runtime/help-file-row-dom/final-proof.json` и связанных журналах. Отдельная визуальная проверка в браузере или на нативном устройстве для этой правки не заявляется.

Исправление не требует API-развёртывания, нового native runtime или OTA; такие действия не выполняются. Основные Metro/T3 и пользовательские данные сохраняются.

## Восстановление

Код: `src/features/help/components/HelpFileRow.tsx`, `HelpMessageBubble.tsx` в том же каталоге. Связанные тесты: `helpFileRowDom`, `helpFileRow`, `helpFileAttachment`, `helpAssistantFiles`, `helpMessageBubble`; `jest.config.js` подключает отдельный DOM-набор. Снимок содержит текущие версии ограниченного списка файлов и может включать сохранённые конкурентные изменения; перед восстановлением согласовать их с актуальной веткой.

Техническая инструкция хранится в Nextcloud с доступом IT/admin. Исходники, SHA-256 и доказательства — в закрытой папке «Восстановление компании». Архив не содержит env, ключей, паролей, токенов, переписок, пользовательских файлов или скриншотов. Учётные данные остаются в отдельном зашифрованном архиве доступа.
