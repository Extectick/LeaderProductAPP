# Выбор обращения для пересылки

Обновление интерфейса Help, 07.11.2026. Окно «Переслать в обращение» использует тот же ряд обращения, что и основной список: аватар сотрудника или ассистента, номер, название, превью последнего сообщения, дату и счётчик непрочитанных. Общий `HelpTicketRow` также поддерживает черновик и индикатор набора текста. Логика основного списка не дублируется внутри окна.

## Компоновка и прокрутка

`HelpForwardSheet` переиспользует `HelpSheet`: на desktop это существующий диалог шириной до 560, на мобильных платформах — прежняя нижняя панель. Высота списка ограничена 456 и доступной высотой окна с учётом safe area; короткий список занимает меньше места. Боковые отступы согласованы с обычным рядом обращения.

Список имеет один `ScrollView`. Внешний `HelpSheet` получает `scrollable=false`, поэтому второй прокручиваемый контейнер и дублирующая полоса не создаются. Web переиспользует `HelpWebScrollbar` основного списка: перетаскивание, колесо и управление клавиатурой работают с тем же scroll node. На native сохраняется системный индикатор прокрутки. Другие вызовы `HelpSheet` сохраняют прежнее поведение по умолчанию.

## Доступ и отправка

В выборе остаются только OPEN-обращения, где текущий пользователь является владельцем или участником; текущее обращение исключено. Это существующий фильтр интерфейса, серверные проверки доступа сохраняются. Меню обращения и служебная регистрация диагностических refs в окне выбора не включаются.

Выбор вызывает прежнюю отправку сообщения с `forwardedFromId`. Пока запрос выполняется, повторный выбор блокируется синхронным guard и disabled-состоянием строк. Успех закрывает соответствующее окно и показывает подтверждение. При ошибке окно остаётся открытым, ошибка показывается существующим способом, после завершения доступна повторная попытка. При отсутствии направлений показывается понятное пустое состояние.

## Проверки и восстановление

Пройдено 146 тестов в 5 наборах, TypeScript без ошибок, Expo Doctor 20/20, зависимости актуальны. Доказательства записаны в `.dev-runtime/help-forward-redesign/final-proof.json` и журналы. Покрываются общий ряд, адаптивный список, фильтрация, отсутствие второго scroll owner, отправка и повтор после ошибки. Отдельная визуальная проверка в браузере или на нативном устройстве не заявляется. API deployment, OTA и native release для изменения не выполняются; основные Metro и T3 не перезапускаются.

Файлы: `HelpScreen.tsx`; `components/HelpForwardSheet.tsx`, `HelpTicketRow.tsx`, `HelpPrimitives.tsx` и существующие `HelpWebScrollbar.tsx`/`HelpWebScrollbar.web.tsx` в `src/features/help`. Общий расчёт полосы — `helpWebScrollbar.ts`. Техническая инструкция хранится в Nextcloud с доступом IT/admin; ограниченный архив исходников и доказательств — в закрытой папке «Восстановление компании». Снимок может включать сохранённые конкурентные изменения; перед восстановлением согласовать его с актуальной веткой. Env, ключи, пароли, токены, переписки, пользовательские файлы и скриншоты в архив не включаются.
