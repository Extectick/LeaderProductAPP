# Каталог сервисов и «Помощь»

## Общая шапка и материал

- `components/ui/appBlurTokens.ts` — общие интенсивность, web radius и границы затухания.
- `AppScreenBlur.tsx` — один материал для шапок и dock. До привязки native target поверхность прозрачна, без белой заглушки.
- `ScreenBlurProvider` принадлежит стеку сервисов; `ScreenBlurTarget` регистрирует только текущий экран и освобождает свой target при уходе.
- Шапка «Помощи» принадлежит маршруту с первого descriptor; общий AppHeader для него всегда выключен.
- Каталог — общий `ServicesCatalogScreen` для native/web: одна колонка, иконка 36dp в поле 56dp, плоские строки. Верхний отступ соответствует измеренной flat-шапке.
- Показываются сохранённые разрешённые сервисы. Пустой старый snapshot ожидает обновления прав; встроенный каталог не подставляется вместо прав пользователя.

## Открытие чата

Известное описание обращения появляется сразу. Ожидание занятого локального чтения ограничено 180ms онлайн / 1500ms офлайн; при доступном сервере используется сетевой ответ. Долгая запись страницы не удерживает открытие. SQLite-транзакции продолжаются, поздние результаты ограничены текущей учётной записью и поколением навигации. Ошибка открытия возвращает интерактивный список с возможностью повторить.

Нажатие даты, начало которой уже видно, не создаёт новую навигацию, snapshot или загрузку. Если предыдущий переход ещё идёт, он отменяется. Карточка исходного обращения использует общий с шапкой `HelpTicketHeading`.

## Android IME

Требуется **новая нативная сборка**: `LeaderHelpChatLayout` экспортирует `imeInsetsVersion=2`, `tailMotionVersion=2`. Один OTA не добавляет этот native-код.

- `WindowInsetsAnimationCompat` двигает dock и меняет видимую область списка на UI thread в каждом кадре.
- Учитывается уже уменьшенное системное окно: второй inset не добавляется.
- Финальный `onImeInsetChange` синхронизирует Yoga; native-компенсация после этого становится нулевой.
- Во время IME/изменений viewport/composer отдельная presentation spring отключена. У конца списка сохраняется зазор 12dp; выше в истории автоматическая прокрутка не захватывает управление.
- Диагностика: `imeBottom`, `imeAnimating`, `dockImeTranslation`, `geometryMotionSuppressed`, `presentationOffset`.

Текст принятого и ожидающего сообщения имеет одинаковые метрики Android без font padding. Резерв под время состоит только из неразрывных пробельных символов: Fabric не может нарисовать второе время даже при игнорировании прозрачного span.

## Целевые проверки

На Android проверены реальные открытие/закрытие клавиатуры и отсутствие остаточных native-смещений. В браузере проверены светлая/тёмная тема каталога, прокрутка под шапкой и карточка ссылки; повторное нажатие видимой даты дало 0px смещения. Стенд `qa/help-preview` использует реальные UI-компоненты с локальными данными; это не проверка авторизации, socket или состояния SQLite на конкретном телефоне.

Dev API обращения №1 при диагностике возвращал 6 сообщений с HTTP200; зависшее локальное чтение и запись воспроизведены отдельными регрессионными тестами.
