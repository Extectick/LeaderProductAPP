# Help: переходы, сообщения и кнопки над полем ввода

Проверка локальной dev-ветки от 2026-11-04. Изменения не опубликованы в OTA.

## Изменения

- Общий AppEdgeBlur отключает захват при потере focus и не показывает предыдущий Android blur target.
- Переход сцены использует измеренную ширину и начинается после готовности позиции истории. При возврате сохраняется геометрия composer до окончания перехода; отправка текста не скрывает клавиатуру.
- Рост короткой истории компенсируется изменением нижнего выравнивания FlashList. Для длинной истории Android сохраняет существующий native tail spring. Компенсация отменяется при ручной прокрутке, навигации и скрытии сцены; ограничена размером viewport.
- HelpGallery получил захват жеста поверх изображения, вертикальное закрытие, горизонтальное перелистывание и ограниченный набор соседних кадров. Галерея объединяет изображения загруженных сообщений без quoted preview-дубликатов.
- Стрелка вниз и стрелки поиска находятся в полноэкранном sibling HelpDockControls. LeaderHelpChatLayout переносит этот слой на тот же dockImeTranslation в том же native frame. Старый APK использует совместимый JS fallback; полная синхронизация требует нового native клиента (dockControlsVersion=1).

## Доказательства

Локальные файлы в игнорируемой папке `dev-builds/help-motion-qa/`:

- `gallery-drag.mp4`, `gallery-drag-mid.png`: Android, изображение следует за вертикальным жестом, фон открывает чат; жест завершает закрытие.
- `dock-ime2.mp4`, `ime-alignment.json`: открытие/закрытие Android IME. Между стрелкой и send-кнопкой постоянное расстояние: 400–400.5 физических пикселей, включая промежуточные кадры. Большой отступ обусловлен сохранённым attachment draft над полем ввода. После закрытия IME нажатие стрелки возвращает вниз и скрывает её.
- Native touch bounds стрелки после исправления: `[946,1807][1046,1907]`; прежде обрезались родителем до `[946,1938][1046,1907]`.
- Web preview: при отправке следующего сообщения замерены промежуточные translateY истории: 66.97, 40.06, 21.82, 10.04, 3.55, 0.71, 0.02 px. Это подтверждает наличие движения между началом и концом, а не только окончательное положение.
- `native-build-jdk21.log`: assembleDebug x86_64 успешен. Установлен в `com.leaderproduct.app.dev` без удаления данных; SHA-256 сертификата совпал с предыдущим dev-клиентом.
- `tests.log`: 204 проверки в 11 целевых suites; последующая `tail-final-tests.log` — 64 проверки двух изменённых suites (заменяет предыдущие 60). Остальные suites не изменялись.
- TypeScript и `git diff --check` прошли.

## Границы проверки

- Локальные fixtures, без отправки сообщений в production.
- Android vertical photo drag и IME/arrow hit testing проверены устройством. Горизонтальный pager и объединение истории дополнительно покрыты component tests; свайп между несколькими фото на Android отдельно не записан.
- Focus lifecycle блюра покрыт regression tests. Изолированный preview всегда focused, поэтому полный native-stack переход Help → реальный каталог приложения здесь не воспроизводился.
- Запись экрана dev-клиента подтверждает геометрию и работу жестов, но не является замером release FPS.
